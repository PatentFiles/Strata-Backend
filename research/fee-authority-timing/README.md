# Fee authority attribution — local diagnostic candidate

This adds no latency optimization, query consolidation, provider request, authority or rollout permission. Existing queries, public probes, conditional branches, original authority clocks and errors remain in place. In particular, history read errors still throw; eligibility query errors still return false; revoked history never falls back to legacy authority.

Only observed ENTRY dispatches create an invocation-local collector. Its synchronous AsyncLocalStorage scope returns the exact existing promise; dispatch entry and inactive or EXIT submission explicitly suppress inherited contexts, including async descendants. Six fixed operations are recorded for each of FINAL_MARKET and WIRE_FEE: standing history query, conditional standing eligibility query, current account fence query, fee public probe, fee review query, and conditional standing renewal query. Inline nonthrowing monotonic markers surround the original await, including inside swallowed-query-error branches. A public probe returning ok:false is rejected; a successful query returning zero rows is completed but does not imply eligibility.

The immutable branded snapshot is added only to the existing dispatch outcome event, never canonical snapshot, book, fee identity, fingerprint, request or proof. There are no additional log events. Counts are capped at20 per fixed group, durations at one hour (invalid/backward clocks yield null), and serialized snapshot size is bounded at4096 bytes. Attempted0 denotes not executed; completed counts settled operations, including rejected. Active counts unfinished measured operations. Capped counts are not exact workload totals. Durations are client elapsed including transport, queueing and locks, NOT database CPU or exclusive wall-time. The public-probe span measures the existing consumer await: if separately enabled prefetch already completed, it does not claim to measure that earlier network work. Nested/overlapping spans must not be summed into invented savings.

No raw SQL, parameter values, errors, URLs, IDs, body data, credentials or arbitrary labels enter the aggregate. Existing observer exceptions and rejected thenables remain detached from trading outcomes. Diagnostic overhead is nonzero: a local20,000-iteration Node microbenchmark produced approximately1834 extra JSON bytes,0.0044ms/event extended serialization versus0.00027ms baseline, and0.0077ms for one capture+marker+snapshot. These informational local figures are not production timing guarantees.
