- **Retry.** The application issues process-local diagnostic proof only from a typed fee-evidence rejection at the first read before the reservation transaction. It binds the validated source digest, account, source and original contract key. Strings, generic transport failures and later calls do not qualify. A disposable integrated run recorded that proof, rejected reuse of the old source, captured a distinct fresh crossing, prevented a third source, and prepared the replacement once without submitting. The separate run-exact.sh script checks PostgreSQL lock ordering, ambiguity and permissions. The SQL is outside the automatically applied migration journal and the replacement writer/reader can only be activated in the disposable simulator. Live runtime is unchanged.
