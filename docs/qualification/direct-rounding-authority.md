# Inactive Direct-rounding authority qualification

`direct-rounding-authority.sql` is a review candidate in test-only documentation, not an application migration. Nothing applies it at startup, grants production access, inserts approvals or enables trading.

Run `pnpm --filter @workspace/api-server run test:direct-rounding-postgres` (or run the same package script from artifacts/api-server). It uses the existing disposable PostgreSQL runner, ignores ambient database credentials, creates a fresh loopback-only cluster, fences external networking and always stops the cluster. PostgreSQL binaries must be installed on PATH; there is no connected-database fallback. The entry-cash-risk aggregate includes this check.

Fourteen groups were verified on PostgreSQL17.11: migration execution; real text account identity; immutable identity/terms/history; both revocation/executor lock orders; pending-generation suppression; READ COMMITTED enforcement; concurrent increasing generations; delayed lower-generation rejection; default-deny RLS and no reader approval privilege; exact registry SQL owner/credential/isolation checks. Additional checks verify credential-revocation ordering in both directions and duplicate credential rows fail closed. Exact credential rows are held FOR SHARE during final authority validation; required production lock privileges remain separate. Harness validates actual server identity before DDL and forbids connection-string query overrides. Blocking is verified using pg_stat_activity before releasing locks.

Scope: minimal representative schema and simulated executor account locking. This does not independently prove the complete executor-to-wire path or actual production grants. Production role policies, authentic review provenance, owner authorization, runtime credential integration and full release qualification remain separate. Final authority reread must occur after account-lock acquisition as a separate statement on the same READ COMMITTED transaction, held through send. No test approves real trading.
