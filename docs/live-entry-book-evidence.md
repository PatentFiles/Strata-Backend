# LIVE canonical book evidence admission

This release requires `entry_quote_evidence` on every LIVE ENTRY source, with no environment opt-out or age-based historical exemption. Existing historical NULL rows remain unchanged and cannot create new LIVE entries. EXIT evidence is unchanged and does not require an ENTRY receipt. Apply the producer's nullable-column migration before the runtime; deploy the matching producer atomically with this consumer.

Preparation, pinned preparation, capability dispatch, pinned final preparation, and the actual synchronous wire callback all validate the compact receipt. It binds exact market, selected side, integer complementary asks and canonical source reference, ordered original local request/header/body timestamps, original evaluation time, and full capacity for the existing fixed $5 paper stake. The five-second limit is not reset or widened. Independent fresh signed-book depth, champion caps, fees, cash/risk/authorization and final wire checks remain mandatory.

`evidenceDigest` is the existing sorted-key canonical SHA256 of the compact receipt excluding its top-level digest. It is an integrity checksum, NOT provider authentication. `normalizedBookDigest` pins the original normalized ladders but cannot be recalculated from omitted full ladders; `rawResponseDigest` likewise is not a signature. Trusted producer/DB write permissions remain the provenance trust root. A fully fabricated internally consistent receipt written by an actor already authorized to mutate canonical data is not cryptographically distinguishable. The full source is pinned in the intent decision and capability digest, and source row equality prevents unnoticed subsequent edits.

Tests run with actual disposable PostgreSQL and a LIVE-mode fake exchange using actual owned-account/policy/master/stake gates, not a disabled receipt guard. No external requests or trades are made. The fixture explicitly emits matching receipts; legacy SIMULATION fixtures remain legacy to test backward historical paths. Receipt unit tests cover malformed/stripped/oversized/mutated input, recomputed invalid proofs, time boundaries and both sides. Production acknowledgement/fill and contemporaneous liquidity still require subsequent authorized qualification.
